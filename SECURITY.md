# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille sur nclsmgr.com ou dans ce dépôt, merci de me la signaler en privé plutôt que d'ouvrir un ticket public :

- par le [formulaire de signalement privé de GitHub](https://github.com/nic0lasm/nclsmgr.com/security/advisories/new) ;
- ou par courriel à **security@nclsmgr.com**.

Indiquez si possible :

- la page ou le fichier concerné ;
- les étapes pour reproduire le problème ;
- l'impact que vous estimez.

## Engagements

- Accusé de réception sous 72 heures.
- Point d'étape sous 7 jours.
- Correction des failles critiques en priorité, puis publication d'une note dans l'historique du dépôt.
- Remerciements publics si vous le souhaitez.

## Périmètre

Inclus : le site nclsmgr.com, ses sous-domaines et le code de ce dépôt.

Exclus : les attaques par déni de service, l'ingénierie sociale, les tests automatisés à fort volume et les services tiers (Cloudflare, GitHub, OVHcloud), qui ont leurs propres programmes.

Merci de ne pas accéder aux données d'autrui ni de les modifier, et de me laisser le temps de corriger avant toute publication.
